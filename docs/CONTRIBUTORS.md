# Вклад участников

Проект выполнен командой из одного участника; ИИ-ассистент использовался как инструмент разработки
(ТЗ разрешает применение ИИ при подготовке решения). Все решения, проверки и приёмка результата —
за участником.

| Участник | Роль | Вклад |
|---|---|---|
| Меркушев М. М., гр. ПС-12, ПГТУ | капитан, fullstack, экономика | постановка задачи по ТЗ, модель тарифов и денежных потоков, backend (FastAPI + SQLAlchemy), маршрутизация mesh/hub, ledger и идемпотентность, тесты, UI ПВЗ и продавца, Docker, документация, демо-скрипт |
| ИИ-ассистент (Hermes) | инструмент | генерация кода и текстов под контролем участника, прогон тестов, поиск расхождений; не принимал продуктовых решений |

## Проверяемость вклада

* история коммитов: `git log --stat --oneline` — каждый блок landed отдельным коммитом;
* тесты и отчёт воспроизводятся одной командой: `bash scripts/run_tests.sh`;
* демонстрация воспроизводится на живом API: `python3 scripts/demo.py`.

## Ограничения и честность данных

Тарифы, бонусы, штрафы, SLA и лимиты ответственности — параметры предложенной модели, а не
обязательства RWB или действующих партнёров (`economics/params.yaml`, `meta.disclaimer`). Хаб,
магистраль и платёжный шлюз — помеченные заглушки; денежные средства не двигаются.
