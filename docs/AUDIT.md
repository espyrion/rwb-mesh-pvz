# Аудит 2026-11-25: что было → что стало

Аудит провели 8 субагентов (DeepSeek flash) по доменам: A — контракт API, B — деньги и данные, C — логика сети, D — экономмодель, E — фронтенд, F — скрипты/CI/доки, G — мёртвый код, H — сверка с Положением хакатона. Оркестратор — Claude Sonnet 5.5. Правки шли тремя непересекающимися волнами и ручными правками API.

Тесты: было 135 (API) + 14 (экономика) = 149, стало 143 + 28 = 171. `bash scripts/run_tests.sh` — зелёный.

## Фронтенд

- Двойной submit/клик создавал два запроса → общий `withBusy()` (disabled + `aria-busy`).
- Гонка `render()` при быстрых переходах → счётчик поколения `renderSeq`.
- `loadCatalog(); render()` без обработки ошибок → `refreshAfterAction()` с тостом, без `unhandledrejection`.
- У хаба были кнопки «Вывести из строя» → убраны.
- a11y: `#toast` с `aria-live`, узлы/сегменты карты фокусируются с клавиатуры (Enter/Space), фокус на заголовок страницы, skip-link.
- Залипшая ошибка покупателя, английское «Not Found», сравнение маршрутов при одинаковых точках → русские сообщения и валидация.
- На ≤900 px сайдбар давал горизонтальный скролл → исправлено.
- Удалены мёртвые `factCell`, `state.econBase`.
