## 3. Если эксперт спросит про расчёты и модель

Быстрые точки для показа цифр — **Экономика / симуляция**:

- **Стресс-тест 2 000 заказов/день, seed 42, сеть 8×120 = 960 операций:**
  | Метрика | Наивный mesh | Overflow 85 % |
  |---------|--------------|---------------|
  | Опоздания | 2 000 | 953 |
  | Пиковая загрузка | 226 % | 136 % |
  | Маржа маркетплейса | 6,13 % | 10,17 % |
  | Себестоимость заказа | 107,15 ₽ | 124,12 ₽ |
  | Перелив на хаб | — | 746 заказов |
- **Безубыточность ПВЗ — 39 оп/день** при 30 % mesh из мощности 120 (44 без бонуса; пересчитывается ползунком).
- **Хранение и возвраты:** 5 ₽/ячейка/день, алерт на 21-й день, вывоз 60 ₽, на 52-й день прибыль от товара = 0; возврат 7 дней, обратная логистика 60 ₽; штраф SLA 50 ₽.
- **Почему в кабинете ПВЗ прибыль может быть отрицательной:** фиксированные 1 200 ₽/день считаются за весь период от старта виртуальных часов (после демо-прогона это ~22 дня). На 3–5 заказах точка не окупается — это модель, а не баг: безубыточность от 39 оп/день.
- **Скоринг размещения:** score ≥ 60 (оборачиваемость 0,45 / спрос 0,35 / габарит 0,20) → `mesh_pvz`, иначе `hub`.
