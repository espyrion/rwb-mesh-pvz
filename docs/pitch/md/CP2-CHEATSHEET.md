## ЕСЛИ СПРОСЯТ

**Почему в кабинете ПВЗ минус?** Фиксированные затраты 1 200 ₽/день × 22 дня (период от старта часов) против выручки с 5 демо-заказов. Точка выходит в ноль от 39 оп/день — см. блок «День ПВЗ» на вкладке Экономика.

**Где числа?** `economics/params.yaml` → единственный источник. API читает его при старте. `ECON_REPORT.md` генерируется из модели. Тест `test_report.py` сверяет файл с кодом.

**Стек?** FastAPI + SQLAlchemy + SQLite (WAL) + vanilla JS + nginx. Всё в Docker, 2 контейнера. 40 эндпоинтов, 171 тест.

**Что дальше?** План тиражирования: `docs/SCALE.md` (симуляция 2000 заказов/день, переход на PostgreSQL+Redis, шардирование по городам).
