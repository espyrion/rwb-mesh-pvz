# CP2 — Шпаргалка показа «Техническая сторона MVP» (ноутбук, 4:00)

> Вариант 2. Без презентации. Только код, Docker и живые клики.
> Стек: FastAPI (40 эндпоинтов) + SQLAlchemy + SQLite (WAL) + единый модуль `economics`; web — vanilla JS + nginx на `:5173`; API + Swagger на `:8000/docs`.

---

## 1. Подготовка за 5 минут до показа

Перед началом — ровно 4 команды/действия, тихо, пока эксперт садится:

1. **Сброс БД** (чистое состояние для сквозного заказа):
   ```bash
   docker compose down -v && docker compose up -d
   ```
2. **Проверка здоровья (deep)** — ждём `"status": "ok"`:
   ```
   GET http://localhost:8000/api/v1/health/deep
   ```
3. **Открыть 3 вкладки:**
   - `http://localhost:5173` — UI (Кабинет продавца / Кабинет ПВЗ / Демо-кокпит)
   - `http://localhost:8000/docs` — Swagger (40 эндпоинтов)
   - терминал — `pytest` / тесты (149 автотестов, 5/5 сценариев)

API-ключи для авторизации (заголовок `X-API-Key`), держать под рукой:
| Роль | Ключ |
|------|------|
| ПВЗ | `demo-pvz-key` |
| Продавец | `demo-seller-key` |
| Админ | `demo-admin-key` |

## 2. Маршрут показа (ровно 4:00)

### 0:00–0:30 — Связка со вчерашним планом (ЧП1)
> «Вчера обещали три вещи: сквозной цикл городского заказа, встроенную финмодель и 5 нештатных кейсов. Сегодня показываем их в коде и в Docker — не на слайдах.»

Проговорить ровно эти три обещания, показать, что всё уже поднято и зелёное (`health/deep` → `ok`).

### 0:30–1:30 — Сквозной городской заказ (живой)
Маршрут по UI: **Кабинет продавца → Заказы → Собрать → Выдать → Начисления**.

- Показать маршрут **mesh 90 ₽ / 3 ч** против **хаба 135,50 ₽ / 30 ч** — выбрать mesh.
- Показать **проводки по 4 сторонам** (продавец / ПВЗ / курьер/узел / платформа).
- Открыть **карточку покупателя** по токену: **19 049 ₽**, доставка **149 ₽** вместо 159 ₽.
- Свести строки — **сходимость ledger** (балансы сходятся в ноль).

Акцент: единый модуль `economics`, проводки не руками, а одним проходом.

### 1:30–2:30 — Встроенная финмодель
Экраны: **Экономика + Кабинет ПВЗ**, блок «Зелёная зона 4 сторон».

- Открыть ползунок **«Бонус ПВЗ за заказ без хаба»**.
- Живой сдвиг **12 → 5 ₽** и показать пересчёт на глазах:
  - прибыль МП: **382,00 → 389,00 ₽ (+7 ₽)**
  - прибыль ПВЗ: **39,50 → 32,50 ₽**
  - безубыточность ПВЗ: **39 → 42 оп/день**
- Подчеркнуть: пересчёт идёт через API из `economics/params.yaml` + `economics/scenario.py`, не хардкод в UI.

### 2:30–3:40 — Нештатные кейсы в Демо-кокпите
По одному клику, без подготовки:

1. **«Отказ узла»** → split-эвакуация (`parent_batch_id`) + переадресация заказа.
2. **«Длительное хранение»** → виртуальные часы >21 дн + перемещение за 60 ₽.

Дополнительно (если время, по 10 секунд):
- возврат (7 дней);
- хаб/магистраль;
- пик / overflow 85 %;
- восстановление узла.

Коротко открыть **Swagger `/docs`** — 40 эндпоинтов — и ещё раз `GET /api/v1/health/deep`.

### 3:40–4:00 — Итог
- **149 автотестов**, **5/5 сценариев ТЗ** — запустить `pytest` (уже в терминале).
- «Финализируем к **14:45**».

## Три вещи, которые нельзя забыть проговорить

1. Сквозной цикл — **живой**, на сброшенной БД.
2. Финмодель **встроенная**, пересчёт через API, не картинка.
3. 5 нештатных кейсов — **реальные переходы состояния**, а не стабы.

## Шаблон нештатных кейсов (на всякий случай)

| Кейс | Ключевой механик | Что показать |
|------|------------------|--------------|
| Отказ узла | `parent_batch_id` | split-эвакуация, переадресация |

| Восстановление узла | возврат в строй | продолжение партий |
